# Instruções para o Claude neste projeto

Antes de tarefas que envolvam entender a arquitetura, rotas, integrações com
a API ou débitos técnicos conhecidos deste projeto, consulte a pasta
[`wiki/`](./wiki/README.md) — ela contém documentação estrutural já levantada:

- [wiki/visao-geral.md](./wiki/visao-geral.md) — stack, scripts, autenticação, convenções
- [wiki/estrutura-pastas.md](./wiki/estrutura-pastas.md) — organização de `src/`
- [wiki/rotas-paginas.md](./wiki/rotas-paginas.md) — rotas e o que cada página faz
- [wiki/integracao-api.md](./wiki/integracao-api.md) — endpoints consumidos e tipos de domínio
- [wiki/pontos-atencao.md](./wiki/pontos-atencao.md) — bugs e débitos técnicos conhecidos

Sempre que uma mudança tornar algo desses arquivos desatualizado (nova rota,
novo endpoint, novo componente, bug corrigido), atualize o arquivo
correspondente na `wiki/` junto com a mudança de código.
